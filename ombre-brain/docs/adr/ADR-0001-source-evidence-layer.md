# ADR-0001: 隐藏原文证据层

## Decision

Ombre Brain 仍只使用普通事件记忆参与日常浮现和语义检索。结构化调用
`grow(content=共享原文, items=[...])` 时，可以额外把同一份 UTF-8 原文保存一次，
路径为 `<vault>/_sources/src_<sha256>.source`；事件桶通过经过校验的
1-based 闭区间 `source_ranges` 引用其中片段。

`source_read` 是唯一公开读取入口。调用方必须同时给出一个精确桶 ID 与该桶的精确
显式标题。默认 `event` 范围在没有非空行区间时失败关闭；读取共享全文必须显式指定
`full_source`，且调用方需知晓全文可能包含多个事件对应的文字。ID + 标题只是读取意图
门禁，不是身份认证。远程可达的公网或局域网部署必须使用 OAuth/Token；stdio 与经安全
门禁确认的本机回环模式继续遵循既有部署边界。

原文文件按内容寻址、只增不改、读取时校验哈希，并受大小上限保护。自 2.10.1 起，
完整本地备份与 GitHub 备份都会携带这些文件。本地 ZIP 使用
`sources/src_<sha256>.source`，vault 与 GitHub 使用
`_sources/src_<sha256>.source`。为兼容历史数据，缺少所引用证据的 2.10.0 备份仍可
恢复事件桶，但导入结果必须明确报告原文证据缺失。

## Why this is not cognition

证据层不判断什么重要，不给记忆排序，不推断意图，不搜索相关内容，不摘要，也不选择
行动。它只返回已经绑定到一个明确选中事件的原文字节。返回内容会被标记为不可信存储
数据，绝不能作为系统指令执行。

## Why this is not a database feature

这不是通用对话数据库，也不是第二套检索面。系统不提供关联查询、语义查询、任意筛选
或自动原文回忆。内容寻址只用于在保留既有事件记忆模型的前提下，让证据不可变、可去重
并能发现篡改。SHA-256 清单只能验证完整性，不是数字签名，也不能证明备份创建者身份。

## How forgetting still works

原文文件永不参与 `breath`、被动联想、语义索引或衰减计分。`digested`、
`dont_surface`、归档状态和既有衰减逻辑仍控制事件记忆。读取证据不会恢复归档桶，也不会
改变激活度、权重、重要度或时间戳。归档事件的证据仍只能通过同一套精确 ID + 标题读取
门禁访问，并遵循当前部署的鉴权边界；这样日常上下文中的遗忘不会与销毁历史证据混淆。

## How tombstones are preserved

归档与墓碑语义保持不变。原文引用不能重新激活、重建或绕过已删除事件。一个桶归档或
删除时不会顺带删除证据文件，因为同一内容寻址原文可能被多个事件共享；安全且理解引用
关系的垃圾回收不在本决策范围内。物理删除仍只允许既有的可擦除测试数据边界，
`source_read` 不承担擦除职责。

## How present thinking remains with the LLM

运行时不会让模型解释或改写证据，只会在“不可信存储数据”标记中返回受预算约束且显式
分页的片段。当前 LLM 可以把历史材料作为上下文，但当下的推理、判断与行动选择仍由
当前对话中的 LLM 完成。

## Rejected alternatives

- 把完整对话注入普通浮现会挤占上下文，并悄悄把证据变成当前指引。
- 在原文层做语义搜索会形成第二套回忆系统，也可能泄露无关私密内容。
- 为每个事件复制整份原文会放大存储，并让不可变一致性更难验证。
- 把标题当作身份认证并不安全；远程可达部署仍必须启用端点鉴权。
- 把空事件范围解释为允许返回全文会失败开放并暴露无关文字。
- 备份不携带证据会产生表面成功、实际永久悬空的引用。
- 一个事件归档时删除共享原文会破坏其他事件，并把遗忘混同为不可逆擦除。

## Tests required

回归测试与属性式测试必须覆盖：精确 ID/标题门禁、形似 prompt 注入的不可信原文、空范围
与越界范围、显式全文读取、完整响应 token 预算、分页游标、响应头控制字符、畸形引用、
UTF-8/大小/哈希/路径/符号链接拒绝、包含不支持硬链接文件系统在内的不可变并发发布、
本地与 GitHub 备份恢复、旧包缺失证据警告，以及人工元数据优先级。测试只能使用临时
vault 或一次性 Docker 卷，绝不能读写真实 `buckets/` 目录。
