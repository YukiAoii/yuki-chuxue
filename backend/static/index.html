常见问题

你可能想问

要花钱吗？

软件本身免费。聊天按 DeepSeek 官方价格计费，直接从你自己申请的 Key 里扣 —— 我们不碰你的钱，也看不到你的账单。

我的聊天记录会被别人看到吗？

不会。记录存在这台手机的本地数据库里，只有你和 Ta 的那次对话会发给你自己的 API 账号。 卸载应用就等于全部清掉。

换手机之后 Ta 还在吗？

人设和记忆目前不跟着账号走。应用内有导出备份，换机时导出再导入即可。

能不能用别的模型？

能。设置 → 连接设置里可以建多个「分组」，一份用官方、一份用中转，各自配地址与密钥， 互不干扰。默认那份仍然是 DeepSeek —— 围绕它的缓存机制做过优化。

下载下来的是最新版吗？

是。这一页的版本信息每次都是现读的，所以收藏这一页就够了，不用记版本号。
