## 七、整理规则（下次整理照这个来）

1. **活文档**（HANDOFF / progress）→ 每轮更新，不归档
2. **阶段性快照**（带 `_v1.0` 这类版本号、且已被取代）→ **移到 `archive/`，不删**
   - ⚠️ 文档是资产，删除不可逆；归档保留了"当时怎么想的"
3. **外部参考**（`_refs/`）→ 只读，不进统计
4. **每新增一份文档**，就在本文对应表格里加一行 —— **否则它就成了孤儿文档**
