## ⚠️ 关于文档时效（重要）

本目录的文档分三类，定位不同：

| 类型 | 文档 | 说明 |
|---|---|---|
| **设计意图** | [`../人机恋app开发文档.md`](../人机恋app开发文档.md) | 写在实现**之前**，记录"为什么这么设计"。**与今天代码有差异的部分，已在文首「先读这一段」中逐条列出** —— 照做前先读那一段 |
| **阶段性快照** | `archive/` 下的全部 | 保留**当时**的状态，不代表今天。仅供追溯设计演进 —— 例如 `架构现状_v1.0.md` 停在 v0.35.0，之后的三块结构性变化（心潮接入、云端记忆、界面美化）它都没有 |
| **当前状态** | 仓库根 [`README.md`](../README.md)、以及 `人机恋app开发文档.md` 的「v0.35 → v0.61.57 的重大变化」一节 | 想知道**现在长什么样**，看这两处 |

> `archive/` 保留的是当时的决策过程。判断当下行为时不要以它们为准。
